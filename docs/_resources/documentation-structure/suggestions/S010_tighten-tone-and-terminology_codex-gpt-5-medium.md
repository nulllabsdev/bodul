## Issue

The guide uses several informal or potentially inconsistent phrases, including
"road travelled" on line 12, "Future you" on line 127, and "such a single
document rather than a folder" on line 140. These phrases are understandable,
but they make the guide feel less like a stable repository policy and more like
an informal note.

## Suggestion

Revise the wording to use consistent policy-oriented terminology. For example,
replace "road travelled" with "audit history", replace "Future you can
reconstruct every choice" with "Maintainers can reconstruct every choice", and
clarify the single-file alternative sentence so it does not imply a document is
a folder.
