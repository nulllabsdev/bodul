## Issue

The folder tree on lines 35-43 includes `research/`, `reviews/`, and `drafts/`,
but the rest of the guide only defines the suggestion and proposal workflow.
Writers do not get rules for when to create these optional folders, what belongs
in each one, or whether they should be linked from `INDEX.md`.

## Suggestion

Add a short subsection after the recommended folder structure that defines
required folders versus optional folders. Mark `suggestions/` and `proposals/`
as workflow folders, describe when `research/`, `reviews/`, and `drafts/` are
useful, and state that resources worth preserving should be linked from
`INDEX.md`.
