## Issue

The guide presents one `INDEX.md` example on lines 71-86 with `## Sources Used`,
`## Decision Log`, and `## Open Questions`. The suggestion workflow section
later states that `suggestion-driven-documentation.md` is normative for
suggestion and proposal lifecycle rules, and that guide now defines a different
suggestion-driven INDEX schema centered on `## Suggestions` and `## Proposals`.
Readers of this document still see only the research-oriented example, so they
can apply the wrong INDEX shape to a document that is under suggestion-driven
review.

## Suggestion

Split the INDEX guidance into two explicit variants: one example for
research-driven documents, and one for suggestion-driven documents. If you want
to keep a single example, label it clearly as the research-oriented variant and
link directly to the suggestion-driven INDEX schema for documents under review.
